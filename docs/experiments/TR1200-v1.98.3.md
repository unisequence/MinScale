# Cudy TR1200 size experiment: Tailscale v1.98.3

This is a historical size and startup experiment, not a production release.
The package was unsigned and the test covered only a short functional smoke
run.

## Device and build

- Device: Cudy TR1200 v1, MediaTek MT7628AN, `mipsel_24kc`
- Firmware: OpenWrt 25.12.5, Linux 6.12.94
- Memory and storage: 128 MiB RAM, 16 MiB flash
- Free writable overlay before installing: about 8.8 MiB
- Tailscale source: v1.98.3; Go toolchain: 1.26.8
- Target: Linux MIPS little-endian, soft-float

## Size results

| Build | Executable or APK size | Change from official APK |
| --- | ---: | ---: |
| Official OpenWrt APK | 9,791,990 B | — |
| Official package's `tailscaled` | 30,515,456 B | — |
| Same OpenWrt tags, also omitting netstack, Serve, and SSH | 25,023,328 B | — |
| Router-min feature profile, stripped daemon | 17,850,080 B | — |
| Router-min daemon packed with UPX 5.2.1 | 4,036,868 B | — |
| Test APK with UPX daemon | 4,039,778 B | −58.7% |

The router-min profile was generated with `cmd/featuretags --min` and an
explicit keep list. It retained the CLI, DNS code, OS routing, route and exit
node support, port mapping, DERP, NAT traversal, TUN, Tailnet Lock, and Unix
socket identity support. It omitted Tailscale SSH, Serve/Funnel, the gVisor
userspace netstack, Drive/Taildrop, BIRD, Kubernetes/AWS integrations, and
debugging and desktop-oriented features. The exact tags are in the build
script.

The executable and APK numbers measure different things: the APK also contains
the init script, config, and package metadata. The package was named
`tailscale-small`; it uses the same `/usr/sbin/tailscale*` paths as the official
package and must not be installed alongside it.

## Runtime observations

Both the unpacked and UPX-packed executables started and created `tailscale0`.
With no node registration, RSS was about 23 MiB. A short Headscale smoke test
registered an ephemeral node, reached a Windows peer through DERP, and reached
a Linux peer first through DERP and then directly. TSMP worked. `netcheck`
reported UDP and IPv4; IPv6 was unavailable from the router during the test.

The paired logged-out RSS samples were 23,088 KiB for the regular executable
and 23,108 KiB for UPX. Running `tailscaled --version` took 0.06 seconds with
the regular executable and 2.98 seconds real / 2.84 seconds user with UPX.
The connected sample after a short quiet period was 27,916–28,168 KiB, with
10,368–10,620 KiB `RssAnon`, about 740 KiB `RssFile`, and no swap.

The test used `--accept-dns=false`. DNS transport, sustained TCP/UDP throughput,
parallel streams, long-duration memory recovery, and a soak were not tested.
The RSS observations are short samples and do not establish a stable long-term
memory floor.

## Artifact provenance

The historical test APK had SHA-256:

```text
2e406442376018d296d86740504da817a4d13abe486de253e862d6b7c78233da
```

The test package was unsigned. It was removed after the test and is not
published as a supported release. The build script documents the original
local OpenWrt MIPS toolchain requirements; package metadata can vary when the
feed files or packaging tools change.

The historical recipe is [build-mipsel.sh](../../experiments/tr1200-v1.98.3/build-mipsel.sh).
It expects an OpenWrt 25.12.5 source tree with the matching MIPS toolchain and
the Tailscale v1.98.3 tag in a local checkout. It uses UPX and must not be
treated as the production build recipe.
