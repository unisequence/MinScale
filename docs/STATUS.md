# Project status

MinScale is in the build-profile and validation stage. The TR1200 v1.98.3
experiment established that a smaller Tailscale package can start and connect
on the target, but it did not validate the router as a production client.

The next release candidate should use a current upstream release and must be
tested on a device that can be safely restarted. No device install, service
restart, or traffic test is part of the current repository setup.

There is no supported MinScale package release at this time.
